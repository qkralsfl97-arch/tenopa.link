# 과제 지식관리 Vault

## 구조
과제별로 폴더를 분리하고, 각 과제 폴더 안에 `raw/`와 `wiki/`를 둡니다.

```
<과제명>/
  raw/    원본 자료 (팀즈 대화, 이메일, 회의록, 지침서, 실적 데이터 등)
  wiki/   raw를 정리한 요약 노트 (핵심 수치, 논의 흐름, 미결사항, 갭 분석)
```

## 현재 과제
- 마이크로바이옴
- 26국바빅
- 국보연전략성과

## 작업 흐름
1. 원본 자료 투입 → 해당 과제의 `raw/`에 저장 (파일명에 날짜 포함 권장, 예: `2026-07-30_팀즈_업무보고.md`)
2. 인제스트 → `raw/` 내용을 분석해 `wiki/`에 구조화된 요약 노트 생성
   - 핵심 성과 수치 추출·보존
   - 회의 논의 흐름 및 미결사항 정리
   - 지침 요구사항과 실적 간 갭 분석
3. 검색·활용 → 노트 간 링크, 키워드 검색, 자연어 질의응답으로 보고서 작성에 활용
